# 页面状态 · 骨架图(加载占位态)

> **是什么**:页面数据加载中的占位状态。不单独出 UI,由已生成的页面按本规则转换。
> **何时用**:用户要「骨架图 / 骨架屏 / 加载态 / loading 占位」。
> **参考实现**:`assets/components/skeleton.html`(左原页面、右转换结果;内含转换器 `<script id="gj-skeleton">`)。
> **来源**:Figma 组件库 V2.0「7.6.1 骨架图」(节点 `4683:28068`),源稿标注「未验证」,使用中迭代。

## 1. 怎么做

1. 先按本 skill 做出页面的正常态。
2. 把 `<script id="gj-skeleton">` 整块复制进页面,渲染完成后调用 `GJSkeleton.apply(页面容器)`。
3. 页面级标题栏 / tab(C04)需在外层加 `data-sk-keep`;其余识别不准时用 `data-sk-*` 标记补,标记表见脚本头注。
4. 不能跑脚本时(静态稿),按第 2–4 节手工画。

## 2. 保留原样

- 状态栏、顶部导航(含搜索框与图标)、底部导航(含选中态)、页面级标题栏 / tab。
- 页面背景、模块卡片(底色、圆角、描边)、分割线、分页符。

原则:页面结构不变,只把要等数据的内容换成色块;色块是概括,不还原细节。

## 3. 换成色块

数值为常用档,不必卡死。

| 内容 | 换法 |
|---|---|
| 文字 | 每行一块,宽 ≈ 该行文字宽。高:36 → 50 · 32 标题(字重 ≥500)→ 44 · 32 内容 / 28 → 36 · 24 → 24;表外字号 ≈ 字号。色块至少比行高小 4,上下行留缝 |
| 图标 | 一级图标 64 → 50×50 居中;其他图标按 50/64 同比缩小,取偶数 |
| 图片、图表、标签等带底或描边的小件、带涨跌底色的数据卡(如 行情/指数行情卡片) | 同尺寸整块 |
| 内容区 tab | 每个 tab 一块,选中 `--H3`(#E2E8F2);胶囊 tab 保持胶囊形 |
| 关键大按钮(高 ≥80 的主按钮) | 整块 `--CP0` 30% 透明度;其余按钮同普通整块 |

- **同一行等高**:同一行的文字与小件取该行文字色块的高度,对齐同一中线。
- **零碎省略**:原件最长边 <28 的小图标(排序箭头、更多箭头等)和宽或高 <16 的色块不画。

## 4. 颜色、圆角、动效

- **颜色**:白底上 `--CB2`(#F2F4F8);灰底上 #87878D 10% 透明度。不出现涨跌色、tick 闪烁底等数据状态色。
- **圆角**:文字、图标及与文字同行的小件统一 8(`--RD2`);其余整块沿用原件圆角。
- **动效**:倾斜约 105°、边缘柔和的白色光带从左向右扫过整个页面,全部色块共用一条;2.4s 一轮循环,缓入缓出;系统开启「减少动态效果」时关闭。

## 5. 自检

- [ ] 保留区与正常态一致,卡片轮廓、间距不变
- [ ] 保留区以外无真实文字、数字、图标、涨跌色
- [ ] 色块与原内容位置对应、同行等高、彼此有缝,无零碎小块
- [ ] 有流光动画
