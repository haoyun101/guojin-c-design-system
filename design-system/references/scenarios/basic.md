# 业务场景:基础

> 业务域:**基础**(含「首页」「智能体」两子域;一级框架类页面归此)。
> **取用规则(三层架构)**:做本场景页面时,**优先用本文件**;未覆盖的项回退「通用组件」(`references/components.md`)→「基础规范」(`references/foundations.md`)。与全局规范的差异属**合法场景覆盖**。
> **命名**:本文件组件全限定名带**二级前缀「基础/{子域}/…」**(子域:首页 / 智能体),例:基础/首页/导航栏-顶部。

## 1. 场景定位与范围
客户端基础框架与一级入口页面。当前两子域:
- **首页**:一级页面·首页,含首页专属导航与交互。
- **智能体**:AI 投顾对话 / 详情、智能体常规页;场景专属渐变 / 浅蓝背景体系。
