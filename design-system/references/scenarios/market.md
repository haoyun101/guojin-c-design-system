## 1. 场景定位与范围
客户端一级页面·行情域:自选、市场、行情三个一级入口合并为一个场景(用户拍板,后续有变动再协商)。

> **个股标签**已归**通用组件层**(`references/components.md` C13 标签 · 个股标签描边款)——因其用于自选 / 交易 / 新股等多场景(≥2),按规则归通用,不在本场景层。行情页用到时直接取用通用层的个股标签。

### 3.1 行情/自选个股列表项(v3.10.0)

**标的名称区**:left SP6(24px) · 宽 192(右边缘 216)。**页面落地对齐**:配套表头(C14)左格右边缘须对齐此处(216),保证表头排序列与数据列横滑对齐。

**左块**(left SP6(24px),垂直居中):
- 股名:PingFang SC Regular **32 / 48** · ct1 #0f0f1b
- 第二行(gap SP1(4px)):代码 GJType Medium **24 / 32** · ct4 #87878d + **个股标签**(复用 C13,0~N 个,gap SP1(4px))

**右块**(right SP6(24px),三列右对齐,列宽 170):最新价 / 涨幅 / 涨跌 · GJType **Medium(字重 500)** · **36px** · 涨 cs1 #f93838 / 跌 cs2 #05b063 / 平 cs3 #55555e。
> ⚠️ GJType 合法字重仅 **Regular/Medium/Bold = 400/500/700**(见 foundations,无 600 文件)。数字与代码均 **Medium=500**,不写 600(600 非 GJType 字重,且与「Medium」标签矛盾)。

**行为 — 实时变动闪烁(tick flash)**:价格实时刷新时,按本次变动方向整行背景**闪一下再消退**——涨 cb13 红8% / 跌 cb27 绿8%(transparent → tint 横向渐变)。默认态白底,非静态涨跌底色。

**个股标签**:复用通用 C13 个股标签(描边款 H32 RD1(4px)),含「描边-only」(科 / 融,cl3/cp0)与「描边 + 淡底」(好股 cb4、持 cb14/cl5/cf3)变体。

**字体硬规则**:数字 Figma 原 D-DIN,入库统一 **GJType**(WF 4.11)。
**参考实现**:`assets/components/scenarios/market/stock-list-item.html`。

### 3.2 行情/指数行情卡片(v3.13.0)
原 Figma「设计系统制作」`g5ELYIx598jTHLEXbeqJR8` 组合 `93:3661`。自选/行情页顶部的指数总览条。

**定位**:自选/行情页顶部指数总览条;横排若干指数单卡 + 尾部「资金/资讯」固定入口区。

**构成与嵌套**:
- 组合 = 横排 **N 个「行情卡片」(通用 C15)实例** + 尾部资金资讯入口区 + 右缘箭头。改 C15 → 组合自动跟随,**不就地重写单卡**。
- 单卡的状态/字号/配色一律取自 **C15 行情卡片**(`components.md 十五`);本节只定**组合落地**(容器、自适应宽、资金资讯入口区、箭头)。
- Figma:组合 `93:3661`;单卡 = 佣金宝库 V2.0 component_set(componentKey `4015a32ef2ff3315835c0dd55330ba3d90c2d1b8`,变体 = 指数态涨/跌/平)。

**组合容器**:宽 750 · 高 **178** · 内边距 top SP6(24px) / **bottom SP5(20px)** / 左右 SP6(24px) · 卡间距 SP4(16px)。
> 🚧 底间距 SP5(20px) = 用户拍板,**覆盖 Figma 直读 bottom SP0(0px)(原不对称)**;组合 158→178。📋 入库后 Figma 组合帧宜同步改 178(属 Figma 写回 4.7,需用户「可以」再动)。放回页面:176(顶导)+178=354,与二级 tab 衔接。

**自适应卡宽(落地 C15)**:组合 = 资金资讯固定入口区(144)+ 横排 N 张行情卡片**等分填充剩余宽度**(卡片 `flex:1`,撑满、不留白):
> `卡宽 =(容器宽 − SP6左 − SP6右 − 144资金资讯 − SP4×间距数)÷ 卡数`;自选页 750 + 3 卡 → 每卡 **170**。

**170 是此容器下算出来的,不是固定宽**;容器变 → 卡宽随之填充;资金资讯固定 144、不随之变。

**资金资讯入口区(组合专属,不单拆)**:宽 144 · 高 134 · **无底色**(直读 card4 无 bg fill)。
- 资金 `icon-zixuanzijin`(48,距卡顶 SP6(24px)、left SP2(8px))+ 文字 24(距卡顶 76)· `--CT1`。
- 资讯 `icon-zixuanzixun`(48,距卡顶 SP6(24px)、left 76)+ 文字 24(距卡顶 76)· `--CT1`。

**组合右缘箭头**:`icon-shixinjiantou-you`(20)· **`--CI4`(弱图标 #cccccc)** · 竖向居中,指示横滑/更多。
> ⚠️ 裁决勘误:支线直读把此箭头记作「CT5 #cccccc」,但 CT5(弱文本)浅色实为 #55555E;#cccccc 对应**弱图标 CI4**。按硬规则3「图标走 CI」固化为 `--CI4`——色值不变(#cccccc)、语义正确。

**行为规则**(文字沉淀,本期不做可点 demo):指数卡区可横向滑动(浏览/管理指数),右缘箭头/滑到底 → 进「指数管理」;资金资讯为固定入口区;AI投顾入口本期不做;数值实时刷新随方向变色(平态灰)。

**字体硬规则**:数字 Figma 原 D-DIN-PRO → 入库统一 **GJType**(WF 4.11),仅换字族、字号字重不变(单卡数字规则见 C15)。
**图标**:资金/资讯/箭头右均库内 iconfont(`icon-zixuanzijin` / `icon-zixuanzixun` / `icon-shixinjiantou-you`),无需新增资产。
**归属**:组合属行情单一场景 → 业务层(本文件);其嵌套的**单卡「行情卡片」属通用层 C15**(多场景复用)。
**参考实现**:`assets/components/scenarios/market/stock-index-card.html`。
