# 组件速查卡 · Component Quickcards

> **用途**:每个已登记组件一张小卡——**全限定名 + 形态变体(辨识特征)+ 关键值 + 复用方式**。
> **为什么先读这个**:选组件 / 判形态前先查本卡(约 2KB),命中后再去 `components.md` 对应章读完整规格、`view` 参考实现整段复用。**不必为"长什么样"先 view 62KB 的 components.md 或 251KB 的 demo 文件**。
> **硬规则(SKILL.md 闸门 A2)**:命中库组件 = 必 `view` 参考实现复用、动手前先 `get_design_context` 看截图核形态;**禁止凭 metadata 矩形尺寸脑补形态**。
> 真值以 `components.md` 对应章 + `design-tokens.css` 为准;本卡是导航不是真源,数值有出入以章节为准。

## C01 常规按钮 · `按钮-{风格}-{档}`
- **变体**:风格=深色主 / 浅色主 / 线框辅助 / 灰色;档=XXS/XS/S/M/L/XL(六档,**圆角=高÷2 全胶囊**)。
- **辨识**:有背景实心或线框、全胶囊圆角。一区块/页尽量只一个主按钮(深色主);底部整宽用通栏档。
- **易混**:vs 文字按钮(有/无背景);vs tab(触发动作/切换视图)。
- **复用**:规格见 `components.md#一`(无独立 demo)。

## C02 文字按钮 · `文字按钮-{24|26|28}`
- **变体**:类型=更多 / 展开 / 收起 / 说明 / 更多-list;字重=灰色款 Regular、其余 Medium。
- **辨识**:无背景纯文字、常带方向/功能图标,多作其他组件右侧操作位(如标题栏)。
- **易混**:vs 常规按钮(权重/背景);vs 正文链接;vs tab。
- **复用**:规格见 `components.md#二`(无独立 demo)。

## C03 导航栏-顶部 · `导航栏-顶部-{场景}` ★高频
- **变体(通用档)**:自选交易理财 / 我的 / 二级常规 / 二级tab切换(首页 / AI / 微信小程序在场景层)。
- **关键值**:整高 176(状态栏88+操作栏88);左右安全区 **SP6(24px)**、图标 48、元素间距 SP7(32px);频道 tab 选中 44 Medium / 未选 36 Regular,**tab 间距 SP7(32px)**;一级·自选交易理财档左侧带**小宝**(渐变球容器 72×76,走 SVG,小宝→tab 组间距 **SP6(24px)**);二级返回用线性 `icon-tuichu`;width:100% 两端对齐自适应。
- **辨识**:含系统状态栏 + 频道切换 tab,系统级。频道 tab **不是** tab-下划线(后者内容区,见 C04)。
- **复用**:**整段复用 `assets/components/top-nav.html`** 的 `gj-tnav-bar/left/tabs/tab.is-on/right` 类体系(6 场景变体),**勿自造 navbar 类**。状态栏复用 `status-bar.html`。

## C03 导航栏-底部 · `导航栏-底部` ★★一名两态,**翻车高危区**
> ⚠️ **先走选型路由**:做**一级页面**(首页/自选/我的/交易/理财)底导 → 用【智能体球版】;**通用底导**仅"业务要自定义 N-tab 通用栏"时用。**动手前必 `get_design_context` 看截图确认是哪一种**(凭 metadata `Rectangle 750×166` 脑补成白底 = 本系统实测最大返工源)。
- **【一级页面·智能体球版】(业务变体,bottom-info-bar.html)**
  - **辨识**:持久带**悬浮智能体球** + **底部信息栏**(随 active tab 变);明/黑双肤。
  - **关键值**:智能体球 `gradient/agent-orb-wave`(132×132,球+声波,内含 197KB PNG → **相对路径整文件引用、勿 base64 内联致截断**);信息栏多态:首页=异动通知60 / 自选=个股异动84↕盯盘356 / 我的=大家都在看60 / 交易·理财=无栏;信息栏顶圆角 RD7(32px)、渐变底 CB38/39/40→CB1。
  - **复用**:生成页面时优先读 `assets/components/bottom-info-bar.usage.md` + 本卡,在 BOM 中钉到 `assets/components/bottom-info-bar.html`;默认不全文读取 250KB 参考实现。只有修改/排查该组件本身时才读全文。
- **【通用底导】(规则集/基准,bottom-nav.html)**
  - **辨识**:纯 **N 等分白底条**,**无**智能体球。
  - **关键值**:整高 166(条98+Home68)、图标 48、图标-文字间距 SP1(4px)、文字 24/S7 **Regular 400**(底导特例)、选中 `--CP0` / 未选 `--CT3`、背景 `--CB1`、顶部分割线 `--CL2` 1px;tab 2–5 可配;示意图标用 `assets/icons/bottom-nav/` 五组(home/watchlist/trade/finance/mine,**active 渐变 + inactive 单色成对**,勿用无关字体图标顶替)。
  - **复用**:整段复用 `bottom-nav.html`。
- **一句话辨识**:**有悬浮球+信息栏 → 智能体球版;纯 N 等分白条 → 通用底导。**

## C04 标题栏 & tab 栏 · `标题栏-{一级|二级|三级}` / `tab-{下划线|胶囊|连体}-{档位}(-{左固|等分|通栏})`
- **变体**:标题栏=一级/二级/三级(静态信息层);tab 形态=下划线/胶囊/连体,排布=左固/等分/通栏。原子:tab(被下划线/胶囊嵌套)、标签选项卡(=tab-连体,三档)。
- **辨识**:标题栏静态无切换、在内容区上方(**≠导航栏**系统级)。胶囊 tab=独立筛选项、连体 tab=对等分段。
- **易混**:tab-下划线 ≠ 导航栏频道 tab(字号体系不同,勿混名)。
- **复用**:`title-tab-bar.html`;规格 `components.md#四`。

## C05 开关 · `开关-{M|S}-{开|关}(-禁用)`
- **变体**:M / S;S 档含可选「文案」布尔属性。
- **辨识**:布尔即时二元、当场生效。**唯一带源稿真值投影的组件(仅滑块用阴影)**。
- **易混**:vs 单复选(即时生效 / 随表单提交)。
- **复用**:`switch.html`;规格 `components.md#五`。

## C06 Toast · `toast-{纯文字|左右图文|上下图文}-{白版|黑版}(-{状态})`
- **变体**:形态三型;**状态(成功等)仅图文档有**;圆角 **RD5(20px)**(`--RD5` 专用)。
- **辨识**:轻量、不打断、最顶层、5–7s 自动消失。
- **易混**:vs Modal(不打断无按钮 / 打断需点);vs Sheet;vs 常驻通知条。
- **复用**:`toast.html`;规格 `components.md#六`。

## C07 时间轴 · `时间轴-竖版-{常规/未读 | 点击后/已读}`
- **辨识**:竖向、按时间串事件(快讯/资讯/动态);圆点+连接线+状态驱动配色。
- **易混**:vs 列表项(有无时间序+连线);vs 步骤条(回溯 / 流程进度)。
- **复用**:`timeline.html`;规格 `components.md#七`。

## C08 单复选框 · `单复选框-{常规单选|常规复选|列表勾选}-{状态}`
- **变体**:三子型。**易混**:vs 开关(随表单提交 / 即时);vs 标签(选中与否 / 分类)。

- **复用**:参考实现 `assets/components/progress.html`;规格见 `components.md#九`。

## C10 分页符 · `分页符-{整页-常规版|整页-反白版|滑动}`

## C13 标签 · `标签-{面性}-{色}` / `涨跌标签` / `个股标签-{色}`
- **变体**:通用标签(面性款:深色面性/浅色面性/涨跌)+ 个股标签(描边款:板块/类型/交易状态)。
- **易混**:vs 勾选(分类筛选 / 选中与否)。

## C14 列表表头 · `列表表头`
- **辨识**:左标识区(**三变体**,左区统一宽 216)+ 右可横滑排序列头。
- **资产粒度**:排序三角=**固有资产**(`common/sort-triangle*.svg`,定死);左侧标识图标=**可替换槽位**(由场景选,只定规格不定文件)。
- **复用**:`list-header.html`;规格 `components.md#十四`(注意"页面落地对齐规则":表头列须与列表项列对齐)。

## C15 行情卡片 · `行情卡片-{涨|跌|平}`
- **辨识**:行情指数/标的概览单卡,三状态状态驱动配色(涨 `--CS1`/跌 `--CS2`/平 `--CS3`);**横排等分填充容器**,卡宽由场景按"一屏张数"定。
- **易混**:单卡概览 vs 列表项;状态色严守涨红跌绿(SKILL 硬规则1)。
- **复用**:`market-card.html`;典型落地 `scenarios/market.md#3.2`(N 卡嵌套)。
