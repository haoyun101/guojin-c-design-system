# Page Shells · 页面骨架模板

> 状态:可用初版。AI 生成页面时先选骨架,只填内容插槽,不要改外壳数值。
> 目的:统一安全区、页面层级边距、模块间距和常见列表 / 详情结构,避免每个页面各自手写布局。

## 选择矩阵

| 文件 | 用途 | 关键约束 |
|---|---|---|
| `base-mobile.html` | 通用移动端页面外壳 | `data-level=1` 用一级页面 SP4(16px) 间距;`data-level=2` 用二级页面 SP6(24px) 间距 |
| `home-ops-shell.html` | 首页 / 运营长页 | 适合运营卡片、图标宫格、横向模块的纵向堆叠 |
| `detail-tab-shell.html` | 二级详情 + 吸顶 tab | 吸顶 tab 复用 C04 `tab-下划线-二级` |
| `list-shell.html` | 列表 / 榜单页 | 吸顶表头 + 列表项;涨跌色用 `--CS1` / `--CS2` |

## 使用规则

1. 每个内容模块放进 `<section class="gj-module">`。
2. 模块垂直间距由 `<main>` 的 `gap` 单点控制,不要给每个模块单独写 `margin-top` 或用 `height` 撑间距。
3. 外壳的状态栏、导航栏、安全区、容器边距属于 P0 级约束,除非先走固化流程,否则不得改。
4. 表单 / 普通详情页骨架尚未单独拆出;当前先用 `base-mobile.html` 承载。
