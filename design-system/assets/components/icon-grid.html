三、嵌套与使用规则组件关系 + 选用判据
  • 嵌套关系:C12 图标宫格 → icon 槽兜底 = C11 占位图-图标(加载中/失败);横滑排布 → C10 分页符-滑动。其余排布一律不嵌分页符。
  • 列数判据:入口≤4 → 4列舒展;=5 → 5列标准;6–10 → 5列×2行;超多/运营横排 → 横滑+分页符。
  • 文案:核心 4 字最佳,超出截断省略;容量上限 64档≤5字 / 88档≤6字;末格沿用「全部功能」入口约定。
  • 槽位:icon 为正方形固定槽位,圆角由上传图标决定,组件不强加;无点击/按压态。
