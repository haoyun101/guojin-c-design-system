# GLOSSARY · 术语字典

> 本字典 = **快速查阅索引**。遇到不认识的 token 缩写 / 命名 / skill 流程术语,以本表为准、防止同义词野蛮生长。
> **真源不在这**:颜色/尺寸的值在 `assets/design-tokens.css`;命名与硬规则在 `SKILL.md`;组件清单在 `references/components.md` + `component-quickcards.md`。本表只解释"是什么 / 怎么读",**值与规则以真源为准**。

**怎么查**:token 前缀(CT/CS/CF…)→ **§1** · 颜色色族(R/G/B…)→ **§2** · 圆角间距(`--RD*`/`--SP*`)→ **§3** · skill 流程词(BOM/闸门/外壳/双模式)→ **§4** · 设计约定(涨红跌绿/全限定命名/场景…)→ **§5** · 易混对照 → **§6**。

## §1 语义 token 前缀(按用途选色,出图第一步)

| 前缀 | 全称 | 含义 | 读法示例 |
|---|---|---|---|
| CP | Color / Primary | 品牌色(仅红) | `--CP0` = 品牌色 |
| CT | Color / Text | 文字色 | `--CT1` 主文本 / CT3 次 / CT4 辅助 / CT6 反白 |
| CS | Color / Stock | 涨跌色(价格) | `--CS1` 涨红 / `--CS2` 跌绿 / `--CS3` 平灰 |
| CN | Color / buttoN | 按钮色(交易动作) | `--CN1` 买红 / `--CN3` 卖蓝 |
| CF | Color / Function | 功能色(失败/成功/链接/提示) | `--CF1` 失败红 / `--CF3` 链接蓝 / `--CF7` 成功绿 |
| CL | Color / Line | 线框 / 分割线色 | `--CL1` 分割线 |
| CI | Color / Icon | 图标色 | `--CI1` 主图标 |
| CH | Color / cHart | 图表色 | — |
| CB | Color / Background | 背景色 | `--CB1` 卡片 / `--CB2` 页面 |

> 数字 = 同族档位(浅→深 / 主→辅),具体色值查 `design-tokens.css`;**优先用语义层(CX),别直接取原子色**。

| 字母 | 色族 | 锚点 |

## §3 间距与圆角 token

圆角使用 `--RD0`–`--RD10`，间距使用 `--SP0`–`--SP10`。数字是档位编号，不是像素值；查值以 `assets/design-tokens.css` 为准。例如 `--RD4`=16px、`--SP6`=24px。

代码引用 `var(--RD4)` / `var(--SP6)`；已有非标准参数保留原值与写法。RD10=6px为特殊圆角，尽量不用；6px间距不属于SP档。`0`、定位偏移(top/left 等)写像素,不套 SP;胶囊 / 全圆角用 `--RD9`(组件章另有规定的按组件章)。

## §4 skill 流程与机制术语(跑流程时会遇到)

- **可靠性三层**:本 skill 的合规保障——① 降摩擦(可复用资产都登记在 `library-index.json`,先查照抄)② 强制 BOM(闸门 A)③ 确定性校验(闸门 B `check-page.py`)。三层缺一不可。
- **BOM(用料清单)**:闸门 A 强制产出的表——把页面要用的每个图标 / 组件 / 关键色字,逐项指到 `library-index.json` 的库内确切引用;查不到才标 `[待]`。**填不出 = 没查库,先查再动手。**
- **闸门 A / A2 / B**:动手前 / 交付前的强制关卡。**A** = 出 BOM;**A2** = 命中库必复用 + 先核形态(别凭 metadata 矩形脑补);**B** = 交付前跑 `check-page.py`,**P0 必须为 0**。
- **任务模式:还原 / 新建**:**还原** = 有 Figma 源(节点 / 截图),用 `get_metadata` / `get_design_context` 核形态;**新建** = 无源(只说"做个 X 页"),**跳过 Figma 工具**,形态以速查卡 + `view` 参考实现为准。
- **page-shell / 页面外壳**:`assets/page-shells/` 的页面骨架,AI 只填内容插槽、**外壳数值禁改**;模块间距交容器 `gap` 单点,别各模块自加 `margin`。
- **data-level**:页面层级 `1|2`,切边距 & 模块间距 **SP4(16px) / SP6(24px)**(一级 / 二级)。
- **data-theme="dark"**:深色模式开关(容器加此属性,语义色自动切,不另写色值)。
- **gj-module**:包每个模块的 `<section>`,塞进 `<main>`,间距由容器 `gap` 决定。
- **速查卡**:`references/component-quickcards.md`,每组件「形态变体 + 辨识特征 + 关键值 + 复用方式」约 2KB;选组件 / 判形态**先查它**,别先吞 62KB 的 components.md。
- **参考实现**:`assets/components/*.html`;命中库的组件必 `view` 并整段 / 按类复用,不就地重写。
- **固化流程**:新业务组件 直读 → 两次确认 → 登记 后才可引用;**未登记禁用**。
- **self_contained / sandbox-header**:widget 沙盒读不到磁盘 → 资产须内嵌;把 `assets/components/sandbox-header.html` 整段粘进 `<body>` 开头,iconfont / 字体 / 底导 / 小宝 / tokens 即就绪。

## §5 设计约定术语

**颜色语义**
- **涨红跌绿**:中国 A 股惯例,上涨用红、下跌用绿,与欧美相反。本系统铁律。
- **买红卖蓝**:交易动作——买入红(`--CN1`)、卖出蓝(`--CN3`)。与「涨跌」分属两组,不可互换。
- **绿色双语义(按语境)**:**价格语境**表「跌」(`--CS2`),**操作结果语境**表「成功」(`--CF7`,如结果页"操作成功")——同色值不同语义;链接用蓝(`--CF3`)。同屏并存时靠位置 / 文案区分,避免误读。
- **白版/黑版**:浅色/深色主题。深色仅覆盖约39个语义 token。

**布局基准**
- **750 基准**:设计稿与实现统一 750px 宽;标注值即实现值,不做 ÷2 换算(v1.6.2 起全系统唯一基准)。
- **安全区**:状态栏、刘海、底部 Home Indicator 等不可放可点击元素的区域。
- **数值真源(SSOT)**:所有颜色 / 尺寸只在 `design-tokens.css` 定义一次,他处一律引用。
- **语义优先**:按用途(文本 / 背景 / 按钮)选 token,而非按颜色。

**命名与内容**
- **全限定命名**:引用组件用「族-形态-档位(-排布)」,档位主键 = Figma 变体值;禁止裸档位(✗「80档」 ✓「tab-连体-80」)。规则见 SKILL.md 总则,各族清单见 components.md 文件头。
- **排布受控词**:tab 栏排布仅三词——左固(左对齐固定间距、超宽横滑)/ 等分(N 等分撑满)/ 通栏(灰底容器整宽)。
- **示意文案占位**:演示产物统一用「标题名称 / 副标题 / 标签1·标签2… / 按钮文案」,禁真实业务词与随意词。
- **源稿真值**:Figma 实测、与 token 档不一致但忠实保留的数值(如胶囊 tab 圆角 36/50),按真值写,不归并 token。

**架构与场景**
- **三层架构**:基础规范(全局)→ 通用组件(≥2 场景复用)→ 业务场景(单一场景专属,`references/scenarios/`);场景已覆盖项优先、未覆盖回退,差异为合法覆盖。
- **场景声明**:使用者明确所做页面属哪个业务场景(受控词 = 8 业务域:基础 / 账户 / 增值 / 行情 / 交易 / 理财 / 资讯 / 端外;基础、端外含子域,用二级前缀,如 基础/首页、基础/AI智能体、端外/微信小程序);未声明时只用全局两层。

## §6 易混对照(防错速查)

| 易混 | 区别 |
|---|---|
| 涨跌色 `CS`(红/绿) vs 买卖色 `CN`(红/蓝) | 价格方向 vs 交易动作;都含红但语义不同,不可互换 |
| 跌绿 `CS2` vs 成功绿 `CF7` | 同色值 G6;**价格语境=跌**、**操作结果语境=成功** |
| 品牌色 `CP`(=红 R6) vs 功能色 `CF` | 品牌色只有红;绿成功 / 蓝链接等都属功能色 CF |
| tab-下划线(C04,内容区) vs 导航栏频道 tab(C03,系统级) | 字号体系不同,勿混名 |
| 底导-智能体球版 vs 通用 N 等分白条 | 有悬浮球+信息栏 / 纯白底条;选错是最大返工源 |
| SP / RD编号 vs 像素值 | 编号按token表查值，如SP6=24px、RD4=16px |
